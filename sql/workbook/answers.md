# Answers — read after predicting

SQL implementations are separately stored in `answers/01-*.sql` through `answers/10-*.sql`; the runner prepends `context.sql`. Baseline values below are fictional fixture results, not historical measurements. Run `npm run sql:verify -- --show` to inspect computed results; the verifier separately checks ties and interruption preservation after printing the baseline.

1. **Counts:** 13 laps, one missing duration, eight candidates. Child-to-child joins multiply matching rows; independent counts preserve grain. `= NULL` selects no rows; use `IS NULL`. A duration of zero would be invalid, not missing.
2. **Coverage:** A seven records/six known durations/three candidates; B six records/six known/five candidates; 99 zero records/zero known/zero candidates and NULL first/last/span. A spans 1–7 with zero interior gaps; B spans 1–7 with one missing number. A LEFT JOIN creates a placeholder row for 99, so COUNT(*) would misleadingly report one. Filtering joined rows in WHERE can remove unmatched entries.
3. **Fastest:** A lap 2 = 90 seconds from three candidates; B lap 2 = 91 from five. 99 has no fastest row. Making A lap 7 equal 90 returns both tied laps. MIN selects a value; joining it back identifies every matching lap.
4. **Median:** A 92, B 95, 99 NULL with sample count zero. With range 1–3, A's eligible [90,92] continuous median is 91; discrete median is 90. These functions answer different questions. Empty samples and unknown measurements never become zero. PostgreSQL's [aggregate documentation](https://www.postgresql.org/docs/18/functions-aggregate.html) specifies null handling and percentile interpolation.
5. **Matched:** lap numbers [2,3,7], three pairs; A−B differences [−1,−3,−3], mean −7/3 (about −2.333333 seconds), median −3. A's individual mean is 278/3; B's is 479/5=95.8: subtracting these gives −47/15 (about −3.133333), **using different samples**. Removing lap equality produces 3×5=15 combinations. Swapping A/B preserves pairs and reverses differences. With no matched rows, count is zero and mean/median/lap array remain NULL.
6. **Stints:** A stint 1 has [90,92], sample two, median/mean 91; A stint 2 has [96], sample one, median/mean 96. B stint has sample five, median 95 and mean 95.8. Inclusive boundaries assign lap 3 to A stint 1 and lap 4 to stint 2; strict bounds discard endpoints. Compound is observed metadata, while fuel/traffic/car/conditions and source exclusions are uncontrolled.
7. **LAG:** A lap 3 changes by +2 seconds. A lap 7 has NULL change because the previous lap's duration/eligibility is unavailable; B lap 7 has NULL because previous observed lap is 5, not 6. Filtering eligible rows before LAG can bridge excluded records; removing the adjacency guard turns that into a misleading consecutive change. The outer display filter leaves lap 2 history available. PostgreSQL's [window tutorial](https://www.postgresql.org/docs/18/tutorial-window.html) explains window calculations and filtering order.
8. **Rolling:** B lap 5 uses eligible laps 3,4,5: (95+93+101)/3=289/3 (about 96.333333). B lap 7's RANGE frame covers lap numbers 5–7: observed two, eligible two, available mean 100, complete mean NULL. ROWS instead includes recorded laps 4,5,7, giving (93+101+99)/3=293/3 (about 97.666667) and misleadingly satisfying the existing three-row completeness check. Restore RANGE; completeness means three consecutive eligible lap numbers.
9. **Timeline:** three observations; the undated notice sorts last. UNION ALL preserves occurrences without a deduplication step. In this projection distinct source/event IDs also distinguish otherwise identical observations; removing those IDs and using UNION could collapse repetitions. No stationary value is inferred from the 20-second pit-lane value. Sorting gives an inspection timeline, not proof of precise on-track event/lap alignment.
10. **Sensitivity:** strict [2,3,7], count three, mean −7/3. Pit-relaxed [2,3,4,5,7], differences [−1,−3,+27,−7,−3], count five, mean 13/5=+2.6. The sign reverses because the sample admits pit-related laps. Ignoring only the pit-event reason admits lap 4 but not pit-out lap 5 in this fixture: four pairs, mean 20/4=+5. The verifier also confirms neutralization and uncertain boundaries cannot enter either mode. This is a selection experiment, not a strategy counterfactual or driver ranking.
